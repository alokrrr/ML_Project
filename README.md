# Student Exam Performance Predictor

A machine-learning web application that estimates a student's mathematics score from their demographic and academic profile, including reading and writing scores. The application uses a Flask interface and a saved scikit-learn preprocessing/model pipeline.

> **Note:** Predictions are estimates generated by a machine-learning model. They are not guarantees of a student's actual performance.

## Features

- Responsive Flask/Jinja prediction interface.
- Inputs for student profile, reading score, and writing score.
- Server-side validation for score values from 0 to 100.
- Model and preprocessing artifacts loaded from the project's `artifacts/` directory.
- Separate data-ingestion, preprocessing, and model-training stages.

## Technology

- Python
- Flask
- pandas and NumPy
- scikit-learn
- CatBoost and XGBoost
- HTML, CSS, and vanilla JavaScript

## Run locally

Run these commands from the project root.

### 1. Create and activate a virtual environment

Windows PowerShell:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
```

Windows Command Prompt:

```bat
py -m venv .venv
.\.venv\Scripts\activate.bat
```

If you already have a working environment, you can use it instead of creating `.venv`.

### 2. Install dependencies

```bash
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

### 3. Start the web application

```bash
python app.py
```

Open [http://127.0.0.1:5000](http://127.0.0.1:5000) in your browser.

The application expects these files to be present:

```text
artifacts/model.pkl
artifacts/preprocessor.pkl
```

Both files are generated by the training pipeline described below.

## Using the application

Complete all fields and select **Generate prediction**. The inputs are:

| Input | Accepted values |
| --- | --- |
| Gender | Female or male |
| Race or ethnicity | Group A, B, C, D, or E |
| Parent or guardian education | Associate's degree, bachelor's degree, high school, master's degree, some college, or some high school |
| Lunch plan | Standard or free/reduced |
| Test preparation | Not completed or completed |
| Reading score | Number from 0 to 100 |
| Writing score | Number from 0 to 100 |

The result is the model's estimated mathematics score. The model does not currently return a confidence score.

## Retrain the model

The training dataset is read from `notebook/data/stud.csv`. Run the training pipeline from the project root:

```bash
python -m src.pipeline.train_pipeline
```

The pipeline:

1. Reads the source CSV and creates a reproducible 80/20 train/test split.
2. Imputes and scales numerical features and imputes/encodes categorical features.
3. Compares configured regression models using cross-validation and test-set R².
4. Saves the selected model and fitted preprocessor under `artifacts/`.

Training may take longer than starting the web application because model selection evaluates multiple estimators and parameter combinations.

| Route | Method | Purpose |

## Notes

- Run the app and training command from the repository root so dataset and training output paths resolve correctly.
- Do not load model pickle files from untrusted sources.
- `artifacts/train.csv`, `artifacts/test.csv`, and `artifacts/data.csv` are generated during ingestion; retraining can overwrite them.
